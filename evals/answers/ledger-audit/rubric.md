### 3. 字段校验：20 分

- 八项校验规则每项 2 分，共 16 分。
- 严格遵守错误优先级：2 分。
- 错误原因使用稳定、机器可读的标识：2 分。

错误标识：

| 校验规则 | 错误标识 |
|---|---|
| `transaction_id` 为空 | `empty_transaction_id` |
| `transaction_id` 重复 | `duplicate_transaction_id` |
| `type` 非法 | `invalid_type` |
| `amount` 不是合法数字 | `invalid_amount` |
| `amount` 小于等于 0 | `non_positive_amount` |
| `amount` 超过两位小数 | `too_many_decimal_places` |
| `status` 非法 | `invalid_status` |
| `created_at` 格式非法 | `invalid_created_at` |
