# dev-main 评分说明（仅评审侧）

每题 1 分，`action` 完全一致才得分。

- M01：工人交回 → 派验收 agent（不是自己验，也不是做的工人验）。
- M02：第 1 次不通过 → 交回原工人修。
- M03：一组 3 轮不过 → 停这组升级，别的组继续。
- M04：合并冲突 → 打回后合的那组。
- M05：开工前 impact 有变化 → 先同步再记基线。
- M06：工人要改范围外文件 → 主 agent 调整派工单和清单，重跑 validate/graph。
- M07：中途需求变化 → 只停受影响的组。
- M08：全部合并后 → 先整体验收。
- M09：整体验收通过且 Q3 → 交 x-qa-gate。
- M10：只有一组 → 不走多 agent 流程。
- M11：无关的 bug → 登记成后续任务。
- M12：整体验收通过且 Q0 → 主 agent 升 ✅ 并交付。
- M13：要改的文件正在被另一组改 → 改成依赖那一组，等它合并后再做。
