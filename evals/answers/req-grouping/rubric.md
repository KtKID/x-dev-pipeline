# req-grouping 评分说明（仅评审侧）

每题 3 分：
- 完整：每个任务行恰好出现在一个组里。
- 硬规则：涉及文件有交集的行同组；`same` 里列出的行同组（含软规则“同一场景的实现和测试不拆开”）。
- 组数：落在 `count` 范围内。

各题考点：
- G01：文件互不重叠，但三处都是小改动 → 1 组（不为并行而拆）。
- G02：T1、T2 都改 date.ts 必须同组；T3、T4 是大块独立功能 → 2–3 组。
- G03：三行都改 src/api/index.ts → 必须 1 组。
- G04：五块大功能互不重叠，用户没说工人数 → 最多 3 组，至少 2 组。
- G05：文件不重叠，但都很小且 T2 依赖 T1 → 1 组。
- G06：用户说只有 2 个工人 → 正好 2 组。
- G07：T1 是实现、T2 是同一场景的测试 → 同组；T3 独立且大 → 2–3 组。
