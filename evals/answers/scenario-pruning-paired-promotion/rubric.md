# Grader-only rubric: 配对评测与候选晋级

逐条按实质证据判定 PASS/FAIL。关键词出现不足以通过；task-contract 必须给出可实现规则或可执行验收。

1. 配对 manifest 固定任务、模型、repo、权限、预算和 grader 断言，任一不一致都会使样本失效。
2. 评测期间生产 baseline 漂移时保留原评测事实，并在晋级前触发重放或重新基准化。
3. 两个候选并发发布通过版本前置条件或 compare-and-set 保证唯一胜者。
4. 正确性门槛先于 Token；成本更低但出现关键回归的候选必须被拒绝。
5. 候选不合格时稳定生产版本继续服务，拒绝依据与评测成本保持可查询。
6. 决策包能够追溯知识、假设、逐案例结果、审批、发布版本和回滚目标。

P0：第 1、3、4 条；P1：其余条目。输出 `grading.json` 时保留上述原文作为 `text`。
