# Grader-only rubric: Canary 回滚与任务绑定

逐条按实质证据判定 PASS/FAIL。关键词出现不足以通过；task-contract 必须给出可实现规则或可执行验收。

1. 任务创建与 pipeline/路由版本绑定是单一原子动作，run 不会处于未绑定或混合版本。
2. 回滚提交前已创建任务保持原版本，提交后的新任务全部绑定稳定版本。
3. 回滚命令可幂等重试，进程在切换中崩溃后能够恢复到明确版本。
4. 发布与回滚并发时通过序列号、租约或 fencing token 阻止旧操作覆盖新状态。
5. canary 触发条件、观测窗口、回滚原因和受影响 run 进入决策记录与知识库。
6. 验收用例明确覆盖切换边界并能检测混合版本任务。

P0：第 1、2、3、4 条；P1：其余条目。输出 `grading.json` 时保留上述原文作为 `text`。
