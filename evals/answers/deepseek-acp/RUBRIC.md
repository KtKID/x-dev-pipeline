# DeepSeek Harness ACP · 评审专用答案 v1

公开题面定义得分范围；官方实现给出可运行参照。按协议行为评分，允许不同模块、同步机制和测试设计。所有运行断言应在真实 Harness 上复跑，文档质量独立评分。

## 官方参考

- 试题起点：`add59a3336f0ab61c55499418081aab76cb550f8`，首个 ACP bridge 提交的父版本。
- 答案：[DeepSeek 官方首个 ACP 实现 `fb9636db4486`](https://github.com/deepseek-ai/deepseek-harness/commit/fb9636db4486eb3abc1395d8842b4ef2e5079441)。`official-reference.patch.gz` 保存这两个提交间的完整补丁，解压后 SHA-256 `4eec5f1488a57fe5b4b7c5637b1ee3684ea0f628367feadac8b5aa181a8e4fcf`，适用 [当时的 BSD 3-Clause 许可证](LICENSE.upstream)。
- `packages/acp/src/index.ts`：Cordis 插件、stdio 接入、会话与进行中请求的所有权、事件投影、恢复与断线清理。`codec.ts`：内容及终态映射。`packages/agent-loop/src/agent.ts` / `packages/agent/src/types.ts`：等待 Agent 空闲的接口及实现。`packages/acp/tests/` 有协议、生命周期、竞态和回放回归。
- 首版与[后续官方自动化 ACP](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/acp/acp/README.md)的会话范围不同。本题使用首版的单会话和 `session/load` 历史回放契约。入队但尚未开始的取消、模型设置、多会话、MCP、审批等行为留给其他题目。

## 运行评分：80 分

`grade.py` 每组 10 分，组内判据全部通过才得分。P0 任一失败，质量门禁失败。评审保留原始帧、fixture 事件和稳定 ID。

| ID | 级别 | 可判定的答案 |
| --- | --- | --- |
| ACP-01 | P0 | 版本回落到 1，声明加载与文本子集；stdout 可逐行解码。相对路径、异于启动目录、额外目录被拒；两个并发创建只成功一个。 |
| ACP-02 | P0 | 两个含 UTF-8 和换行的文本块按顺序传给真实模型夹具；正文分段重建、思考独立、更新先于 `end_turn`，所有更新携带正确会话 ID。 |
| ACP-03 | P0 | 空数组、空文本、混入非文本和未知 ID 返回请求错误，底层无模型调用；同一会话随后可运行有效请求。 |
| ACP-04 | P1 | 真实工具被调用，开始与终态事件顺序正确且 ID 一致；成功和失败分别上报，后续模型回合可正常结束。 |
| ACP-05 | P0 | 上限路径保留正文并返回 `max_tokens`；提供方失败返回 RPC 错误；后续提示正常。 |
| ACP-06 | P0 | 空闲、未知会话取消无副作用；运行中第二个 prompt 被拒；有效取消触发底层中止，原请求恰好结算一次，后续请求独立完成。 |
| ACP-07 | P0 | 已观察到正文增量后关闭 stdin，真实底层模型收到中止，子进程有界退出。 |
| ACP-08 | P0 | 重启后加载同一持久会话，先回放原用户和助手内容，再返回成功；加载过程没有新增模型调用。错误 ID 和跨工作区恢复被拒，并发加载只成功一次，下一轮可执行。 |

## 流水线评分：20 分

每组 5 分，按可定位证据判定。门禁证据独立于 `grade.py` 的 `runtime_passed`；评分记录 `id`、`passed`、证据路径/行号、失败原因、首次引入阶段与发现阶段。

| ID | 级别 | 通过条件 |
| --- | --- | --- |
| PL-01 | P0 | 规格保持题面范围，明确单会话、取消和错误、跨进程恢复的边界；后续进入技术设计前有覆盖该版本的真实确认记录。 |
| PL-02 | P0 | 技术设计交代协议入口与现有 Harness 的边界、请求和会话所有权、错误及回放机制；编号用例覆盖相应场景，确认后才进入任务拆解。 |
| PL-03 | P1 | 任务拆解对齐确认的规格、设计与用例，证据可追到实现和测试；验收用例真实执行，失败或未覆盖项如实记录。 |
| PL-04 | P0 | Verify 与 QA 按实际证据判断结果，运行断言或关键交接失败时正确阻断；交付回执链接可复核的报告。 |

同一根因影响多个断言时，分数仍按断言记录，归因另关联根因。题面之外的官方行为不扣分。运行分与流水线分相加，满分 100；晋级要求 100、P0 全通过、两臂可比且通过 Token 门槛。
