# 问清需求再写 spec

你是执行 x-ask-spec 的 agent。只读下面两个文件，不读仓库里的其他任何文件：

1. `skills/x-ask-spec/SKILL.md`
2. 题目：`evals/problems/ask-spec/cases.json`

每道题是和用户讨论需求时的一个情况，按规则判断下一步。`action` 只能取下面12个值之一：

`先复述理解再提问`、`继续追问还没清楚的类别`、`不重复问，记下答案和来源`、`开始写 spec`、`先给用户看最终复述`、`每轮只问 2–3 个最影响结果的`、`这条记为没定，其他清楚的照常往下走`、`选 5 个标 1 期，其余标 2 期 3 期并告诉用户`、`只写名称、用途和已确认要点`、`在对话里给结论，不写 spec`、`指出冲突请用户决定`、`直接按理解写 spec`

把结果写成一个 JSON 数组，保存到调用方给你的输出路径。不要输出别的文件。格式：

```json
[
  {"id": "A00", "action": "<上面的值之一>", "reason": "一句话理由"}
]
```
