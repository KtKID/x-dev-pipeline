# x-req 分组判断

你是执行 x-req 的 agent。只读下面两个文件，不读仓库里的其他任何文件：

1. `skills/x-req/SKILL.md`（重点读「分组：派给几个工人」）
2. 题目：`evals/problems/req-grouping/cases.json`

每道题给出一个 task 已经拆好的任务行：任务、涉及文件、改动量，以及备注。按规则决定怎么分并行组：一组交给一个工人。

把结果写成一个 JSON 数组，保存到调用方给你的输出路径。不要输出别的文件。`groups` 的键是组名（A、B、C…），值是这一组的任务行；每个任务行只能出现在一个组里。格式：

```json
[
  {"id": "G00", "groups": {"A": ["T1", "T2"], "B": ["T3"]}, "reason": "一句话分组理由"}
]
```
