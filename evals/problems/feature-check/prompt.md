# 功能检查

你是被派去做功能检查的子 agent。只读下面两个文件，不读仓库里的其他任何文件：

1. `skills/x-verify-spec/references/feature-check.md`
2. 题目：`evals/problems/feature-check/cases.json`

每道题给出场景（有时附本轮的设计 D）、生产代码（`production`，有时附带本次 diff 的其他改动）和一个测试文件（`test`）。按「检查内容」判断有没有问题。`answer` 只能取下面12个值之一：没问题写 `通过`，有问题写最主要的那一个问题类型。

`通过`、`漏了要的`、`做了没要的`、`重写了生产逻辑`、`没调用项目代码`、`绕过要测的流程`、`mock 掉了被测对象`、`只断言调用不断言结果`、`断言恒真`、`吞掉失败`、`数据测不出对错`、`没测到场景要的结果`

把结果写成一个 JSON 数组，保存到调用方给你的输出路径。不要输出别的文件。格式：

```json
[
  {"id": "I00", "answer": "<上面的值之一>", "reason": "一句话理由，带关键行"}
]
```
