# 主 agent 的下一步

你是执行 x-dev 的主 agent，负责派工、核对和合并。只读下面两个文件，不读仓库里的其他任何文件：

1. `skills/x-dev/references/parallel-dev.md`
2. 题目：`evals/problems/dev-main/cases.json`

每道题是一个当前状态。按规则判断下一步，`action` 只能取下面十三个值之一：

`自己在这组分支上跑覆盖率核对`、`交回原工人修`、`停这组并升级给用户`、`打回后合的组重做`、`先同步再记新基线`、`调整派工单和清单并重跑校验`、`只停受影响的组`、`整体跑覆盖率和 xdev check`、`交 x-qa-gate`、`不走多 agent 流程`、`登记成后续任务`、`升为已完成并交付`、`把这一行并进那一组`

把结果写成一个 JSON 数组，保存到调用方给你的输出路径。不要输出别的文件。格式：

```json
[
  {"id": "M00", "action": "<十三个值之一>", "reason": "一句话理由"}
]
```
