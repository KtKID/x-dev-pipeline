# 题目项目：社区图书馆借阅系统

下面是这个项目的 `docs/spec/README.md`。所有题目都基于这张表判断。spec 名是目录名，括号里是中文意思，答题时 `spec` 字段填英文名。

| Spec | 状态 | 拥有什么 | 不管什么 |
|---|---|---|---|
| member（读者账号） | 在用 | 读者账号、登录会话、读者等级、账号注销 | 借阅记录 |
| catalog（馆藏目录） | 在用 | 图书条目、馆藏副本数量、检索与排序 | 借还状态 |
| loan（借阅） | 在用 | 借书、还书、续借、借阅数量上限、逾期计算、借阅记录 | 罚款金额与缴纳 |
| fine（罚款） | 在用 | 罚款的生成、金额规则、缴纳方式与缴纳记录、减免 | 逾期天数怎么算（由 loan 决定） |
| message（消息） | 在用 | 消息类型、消息模板、发送渠道（短信、站内信）、发送记录 | 什么时候该发（由调用方决定） |
| engineering（工程） | 在用 | 构建、依赖、CI、部署脚本 | 任何使用者能看到的行为 |

现有消息类型只有一种"通用提醒"：调用方传一段文字，系统原样发出。
