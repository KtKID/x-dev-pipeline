# 工人子 agent 的越界判断

你是被派来做一个并行组的工人子 agent。只读下面两个文件，不读仓库里的其他任何文件：

1. `skills/x-dev/references/parallel-dev.md`
2. 题目：`evals/problems/dev-worker/cases.json`

每道题是开发中遇到的一个情况。按规则判断你该怎么做，`action` 只能取下面七个值之一：

`正常改`、`新建并列出`、`停下报回`、`记进报回问题`、`写进集成时处理`、`继续做其他行`、`在回执里报状态`

把结果写成一个 JSON 数组，保存到调用方给你的输出路径。不要输出别的文件。格式：

```json
[
  {"id": "W00", "action": "<七个值之一>", "reason": "一句话理由"}
]
```
