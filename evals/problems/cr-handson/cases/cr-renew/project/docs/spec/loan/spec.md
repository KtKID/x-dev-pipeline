## feat01: 续借

> 状态：已验收

场景1: 续借延长 14 天
- GIVEN 读者有一笔未逾期的借阅，续借次数少于 2
- WHEN 读者续借
- THEN 到期日往后延 14 天，续借次数加 1

场景2: 逾期不能续借
- GIVEN 借阅已过到期日
- WHEN 读者续借
- THEN 拒绝，抛 OverdueError，到期日不变

## feat02: 查借阅记录

> 状态：已验收

场景1: 读者查自己的借阅
- GIVEN 读者已登录
- WHEN 读者查借阅记录
- THEN 返回这位读者的全部借阅
