## feat01: 续借

场景1: 续借延长 14 天
- GIVEN 未逾期、续借次数少于 2
- WHEN 续借
- THEN 到期日 +14 天，次数 +1

## feat02: 查借阅和还书

场景1: 只能查自己的借阅
- GIVEN 读者已登录
- WHEN 查借阅记录
- THEN 只返回这位读者的借阅

场景2: 只能还自己的书
- GIVEN 读者 A 登录
- WHEN A 还读者 B 的借阅
- THEN 抛 PermissionError
