## feat01: 计算罚款

> 状态：变更中

场景1: 逾期按天计罚
- GIVEN 借阅到期日是 D
- WHEN 读者在 D 之后 N 天还书
- THEN 罚款 N × 50 分

场景2: 按时还书不罚
- GIVEN 借阅到期日是 D
- WHEN 读者在 D 当天或之前还书
- THEN 罚款 0
