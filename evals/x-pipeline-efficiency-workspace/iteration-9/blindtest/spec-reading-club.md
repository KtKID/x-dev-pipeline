# 读书会小程序

让用户在小程序里组队读同一本书。一个人可以创建读书会小组并邀请朋友加入，小组成员每天记录阅读页数和感想来打卡，相互看到连续打卡天数排名和共同阅读进度，还可以在小组里发帖讨论。

## feat01: 创建读书会小组

用户可以新建一个读书会小组，指定小组名字和要读的书。

场景1: 正常创建
- GIVEN 用户已登录，且当前加入的小组不足 5 个
- WHEN 用户填写小组名字和想读的书，然后提交创建
- THEN 小组创建成功，显示小组名字和所选的书，并生成一个邀请码展示给用户

场景2: 小组名字为空
- GIVEN 用户没有填写小组名字
- WHEN 用户提交创建
- THEN 提示"请填写小组名字"，不创建小组

场景3: 没有选书
- GIVEN 用户填写了小组名字但没有选择要读的书
- WHEN 用户提交创建
- THEN 提示"请选择要读的书"，不创建小组

## feat02: 用邀请码加入小组

用户拿到别人给的邀请码后，可以用这个码加入对应的小组。

场景1: 正常加入
- GIVEN 用户已登录，当前加入的小组不足 5 个，且还没有加入过这个小组
- WHEN 用户输入邀请码并填写昵称，然后提交加入
- THEN 用户加入成功，小组里出现这个用户的昵称，用户进入小组首页

场景2: 邀请码不存在
- GIVEN 用户输入了一个没有任何小组对应的邀请码
- WHEN 用户提交加入
- THEN 提示"邀请码无效"，用户不加入任何小组

场景3: 没填昵称
- GIVEN 用户输入了正确的邀请码但没有填写昵称
- WHEN 用户提交加入
- THEN 提示"请填写昵称"，用户不加入小组

场景4: 已加入的小组数量达到上限
- GIVEN 用户已经加入了 5 个小组
- WHEN 用户尝试用邀请码加入一个新的小组
- THEN 提示"最多只能同时加入 5 个小组"，用户不加入这个新小组

场景5: 重复加入同一个小组
- GIVEN 用户已经在这个小组里
- WHEN 用户再次输入这个小组的邀请码提交加入
- THEN 提示"你已经在这个小组里了"，不重复加入

## feat03: 每日阅读打卡

小组成员每天可以记录今天读了哪一页到哪一页，并写几句阅读感想。

场景1: 正常打卡
- GIVEN 用户已加入一个小组，且今天还没有打卡
- WHEN 用户填写起始页、结束页和几句感想，然后提交打卡
- THEN 打卡成功，显示这次记录的页码范围和感想，并提示今天已打卡

场景2: 今天重复打卡
- GIVEN 用户今天已经打过卡
- WHEN 用户再次尝试提交打卡
- THEN 提示"今天已经打过卡了"，不重复记录

场景3: 起始页大于结束页
- GIVEN 用户填写的起始页比结束页还要大
- WHEN 用户提交打卡
- THEN 提示"起始页不能大于结束页"，打卡不成功

场景4: 感想为空
- GIVEN 用户填写了页码但没有写任何感想
- WHEN 用户提交打卡
- THEN 提示"请写几句感想"，打卡不成功

## feat04: 查看连续打卡天数与小组排名

用户可以看到自己连续打卡了多少天，并在小组首页看到所有成员的连续打卡天数排名。

场景1: 查看自己的连续天数
- GIVEN 用户昨天和今天都打了卡
- WHEN 用户查看自己的打卡记录
- THEN 显示连续打卡天数为 2 天

场景2: 中断后重新计算
- GIVEN 用户昨天没有打卡，今天打了卡
- WHEN 用户查看自己的打卡记录
- THEN 连续打卡天数重新从 1 天开始计算

场景3: 查看小组排名
- GIVEN 小组里有多个成员，各自的连续打卡天数不同
- WHEN 用户打开小组首页
- THEN 按连续打卡天数从多到少列出所有成员的昵称和连续天数

场景4: 还没有人打过卡
- GIVEN 小组刚创建，所有成员都没有打过卡
- WHEN 用户打开小组首页查看排名
- THEN 列出所有成员，每个人的连续天数都显示为 0 天

## feat05: 查看小组共同阅读进度

用户可以在小组里看到大家共同推进到了哪一页，这个进度是根据所有成员打卡的平均页数算出来的。

场景1: 正常查看共同进度
- GIVEN 小组里的成员已经各自打了卡，平均打卡到了第 80 页
- WHEN 用户打开小组首页
- THEN 显示小组共同阅读进度为第 80 页

场景2: 还没有任何打卡
- GIVEN 小组刚创建，没有任何成员打过卡
- WHEN 用户打开小组首页查看共同进度
- THEN 共同阅读进度显示为第 0 页（或提示"还没有人开始打卡"）

## feat06: 小组内发帖讨论

小组成员可以在小组里发帖，围绕正在读的书展开讨论。

场景1: 正常发帖
- GIVEN 用户已加入一个小组
- WHEN 用户填写帖子内容并提交
- THEN 帖子出现在小组的讨论区里，显示发帖人的昵称和内容

场景2: 帖子内容为空
- GIVEN 用户没有填写任何帖子内容
- WHEN 用户提交发帖
- THEN 提示"请输入帖子内容"，帖子不发布

## feat07: 退出小组

成员可以退出所在的小组。如果退出的是创建人，且小组里还有其他成员，最早加入的那个成员自动变成新的创建人；如果小组里只剩创建人自己，他退出后小组直接解散。

场景1: 普通成员退出
- GIVEN 用户是小组的普通成员（不是创建人），小组里还有其他成员
- WHEN 用户选择退出小组
- THEN 用户离开小组，不再出现在小组成员列表里，小组继续存在

场景2: 创建人退出，有其他成员
- GIVEN 用户是小组的创建人，小组里还有其他成员
- WHEN 用户选择退出小组
- THEN 用户离开小组，小组里最早加入的那个成员自动变成新的创建人，小组继续存在

场景3: 创建人退出，只剩自己
- GIVEN 用户是小组的创建人，小组里只剩他一个成员
- WHEN 用户选择退出小组
- THEN 小组直接解散，不再存在

场景4: 退出后再加入
- GIVEN 用户已经退出了某个小组
- WHEN 用户用该小组的邀请码重新填写昵称加入
- THEN 用户重新加入小组成功（前提是当前加入的小组不足 5 个）
