# spec-scope · 运行历史

测什么：spec 归属：需求写进哪份 spec、加到已有还是新建。题面在 `evals/problems/spec-scope/`，答案与考点在 `evals/answers/spec-scope/`。

每次运行的产物在 `iteration-N/run-M/` 下：`answer.json` 是答题 agent 交的答案，`grading.json` 是当时的评分结果。分数按当时的题目和答案计算；之后修过的题，老分数不再重算。
