# qdev-spec-routing · 运行历史

测什么：qdev 路由：留 qdev 还是转主线、task 放哪、停不停、技术设计写哪。题面在 `evals/problems/qdev-spec-routing/`，答案与考点在 `evals/answers/qdev-spec-routing/`。

每次运行的产物在 `iteration-N/run-M/` 下：`answer.json` 是答题 agent 交的答案，`grading.json` 是当时的评分结果。分数按当时的题目和答案计算；之后修过的题，老分数不再重算。
