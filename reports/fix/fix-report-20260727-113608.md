# 提交前契约校验修复报告

> 修复时间：2026-07-27 11:36
> 修复人：Codex (x-fix)

## Bug 描述

分类提交前的确定性验证发现两个阻断：

1. `xdev-orchestrator-slimdown` 的 8 个 Scenario 缺少 GIVEN，`REMOVED Requirements` 被 V3 当作活跃 Requirement 校验。
2. `pipeline-eval-report` validator 把历史 `bootstrap-json-v0` run 当作完整评测 run，误报缺少 telemetry、grading 和 evaluation report。

## 根因分析

- OpenSpec 场景沿用了 WHEN/THEN 旧格式；当前 change validator 对 ADDED/MODIFIED Scenario 要求 GIVEN/WHEN/THEN。
- `check_req_scenario` 将整个 delta 文档交给 Scenario 校验器，缺少 REMOVED section 过滤。
- run validator 只有一套完整评测文件清单，缺少对仓库既有 bootstrap profile 的兼容分支。

## 修复方案

- 为 8 个 Scenario 补齐可执行 GIVEN。
- change 校验在进入 V3 前过滤 `## REMOVED Requirements` 段，并增加回归测试。
- 为 `bootstrap-json-v0` 定义 `manifest.json + events.jsonl` 兼容校验；新 run 继续执行完整五文件契约。
- 同步 executor-tools 副本和 manifest。
