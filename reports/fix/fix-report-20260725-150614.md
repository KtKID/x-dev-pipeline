# 风险 ID 契约冲突修复报告

> 修复时间：2026-07-25 15:06
> 修复人：Codex (x-fix)

## Bug 描述

当前运行面同时存在 `AR-NNN`、`A-risk-NNN`、`<namespace>-risk-NNN` 与 adversarial risk v1/v2/v3 多套契约。考试目录的真实 RAG 能召回 `AR-001..005`，随后被 v3 namespace 校验规则拒绝并回退为 `skipped:no-corpus`。

## 根因分析

iteration-7 曾引入可替换 namespace、首条固定为 `A-risk-001` 和历史版本兼容分支；根目录语料与考试目录继续使用 `AR-NNN`。通用 RAG 把 Markdown 标题作为不透明 ID，namespace 结构没有参与 Embedding 或排序；冲突集中发生在 Spec、语料和来源校验层。

## 修复方案

统一当前契约：

```text
adversarial_risk_version: 3
错题 ID：AR-NNN
ARV 来源：RAG:AR-NNN
Scenario 来源：adversarial-review (rag:AR-NNN)
```

保留 ID 格式、全库唯一性和跨文档引用存在性校验。删除 namespace、v1/v2、首条固定 ID 与历史来源兼容分支。独立假设继续使用 `adversarial-review (assumption:<说明>)`。
