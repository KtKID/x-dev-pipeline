# flag checklist 临时副本修复报告

> 修复时间：2026-08-05 15:10
> 修复人：Codex (x-fix)

## Bug 描述

`xdev.py flag` 在 P2 登记或重复登记已 blocked 任务时，持续生成内容相同的 `.dev-checklist.md.flag-<UUID>.tmp`。每个 task 应长期只保留一份 `dev-checklist.md`。

## 根因分析

旧事务协议在每次 flag 调用时无条件创建两份 UUID 临时文件。提交阶段发现正式 checklist 已经匹配目标哈希时直接跳过 replace，对应 checklist 临时文件未被清理。连续 P2 和重复 blocked 登记稳定累积相同副本。

## 修复方案

- 主 agent 按 reviewer 候选顺序串行调用 flag。
- 删除新事务的 UUID 生成与并发 marker 竞争协议。
- 实际内容变化时使用固定 `.<目标名>.flag.tmp`；内容一致时跳过临时文件创建。
- 正常提交、目标已匹配和恢复完成路径统一清理固定临时文件。
- 恢复继续读取 marker 保存的临时路径，兼容升级前已经发布的 UUID pending marker。
- 同步 x-qa-gate/x-dev、OpenSpec、plan、CLAUDE、README 与 `.gitignore` 契约。

## 修改文件

| `CLAUDE.md`、`README.md`、`README_zh.md`、`.gitignore` | 同步仓库级说明并移除 UUID scratch ignore |
