# L2 死代码

找“没人用的代码”：0 引用的函数、类、文件、导出、配置项。**靠工具找，AI 只看工具拿不准的。**

## 脚本做什么（`audit.py l2`）

| 语言 | 用什么 |
|---|---|
| Python | 脚本自带的引用扫描：列出项目里每个顶层函数、类、常量，在全项目代码里按名字找引用。0 引用的直接算死代码；只在测试里被用的单独列出 |
| JS / TS | `npx knip`（能找没用的文件、导出、依赖、类型）；没装就退回 `tsc --noEmit --noUnusedLocals --noUnusedParameters`，并提示装 knip |
| Go | `staticcheck` 的 U1000 或 `deadcode` |

脚本把候选分三类：

- **确认没用**：全项目找不到任何引用。直接成为问题，不用 AI。
- **只有测试在用**：生产代码不用。直接成为问题，写清“只有测试在用”。
- **拿不准**：名字出现在字符串里（可能被 `getattr`、注册表、配置按名字找）；带路由、命令行、插件之类的装饰器；在 `__all__` 或包的导出里；名字像入口（`main`、`handler`）。这一类交给子 agent。

## 子 agent 做什么

只看“拿不准”的候选。每个候选是回执「检查项」表里的一行，检查项写候选名字：

| 结论 | 什么时候 |
|---|---|
| 没问题 | 找到了真实使用的地方（写出调用位置），或它是对外入口（写出谁会调用它） |
| 有问题 | 确认没人用，开一条问题 |
| 没法判断 | 要看项目外的代码或运行时配置才能定，写清要看什么 |

严重度一般是 P2；死代码和在用的代码同名、容易被误用的，算 P1。
