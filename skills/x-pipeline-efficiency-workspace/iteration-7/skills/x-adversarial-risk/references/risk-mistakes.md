# 对抗性风险错题集

每条错题只保存稳定 ID、功能关键词和具体 Risk。检索脚本直接返回匹配条目的关键词与 Risk 正文。

## A-risk-001

关键词：分阶段提交、持久化替换、崩溃恢复、重复前缀
Risk：一个逻辑提交跨越多个持久化动作时，中途崩溃可能留下部分完成状态，导致恢复后的序列不单调或后续提交重复生效。

## A-risk-002

关键词：快照恢复、结构校验、状态版本、历史重放
Risk：结构和类型都合法的快照仍可能包含合法状态转换无法产生的字段组合，恢复后会接受语义不可能的状态。

## A-risk-003

关键词：日志恢复、末条记录、校验和、状态迁移、序列完整性
Risk：编码、字段和校验和都完整的日志末条记录仍可能违反序列或状态转换规则，恢复过程可能把语义非法记录当成有效状态。

## A-risk-004

关键词：幂等请求、失败重试、请求历史、去重标识
Risk：失败请求提前占用幂等标识时，同一标识的后续合法请求可能被错误拒绝或丢失应产生的唯一副作用。

## A-risk-005

关键词：错误响应、公开契约、退出码、字段集合、消息类型
Risk：错误路径只校验 code 或退出码时，顶层字段、message 类型或额外敏感字段可能偏离公开响应契约。
