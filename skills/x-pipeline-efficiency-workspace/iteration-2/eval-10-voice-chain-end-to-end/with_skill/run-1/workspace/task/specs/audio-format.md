# 规范：音频格式

本规范是音频相关数值的真源，代码中禁止另立硬编码。

## 录音文件（设备 → 后端）

| 项 | 值 |
|---|---|
| 容器 | WAV（RIFF），含标准头 |
| 编码 | PCM，16 bit，小端 |
| 声道 | 单声道 |
| 采样率 | 16000 Hz |

设备上传的是**完整 WAV 文件的字节流**（含文件头），按传输块切分：
每块 3200 字节，最后一块可以不足 3200 字节。块的先后顺序即文件字节顺序。

## 设备播放能力（后端 → 设备）

设备播放器只支持：PCM，16 bit，小端，单声道，16000 Hz。
设备内存有限，播放数据同样按块接收。
